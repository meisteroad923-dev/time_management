# TEST 3 — 자동 배치 / 시작 요일 / 우선순위 / 실패

사용 초기 파일: `03_auto_schedule_priority.dat`
테스트 주: `2026-10-26(월)~2026-11-01(일)`

## 사용 방법
각 TEST는 교수자가 직접 조작할 수 있도록 **초기 데이터(.dat)** 와 **실행 절차**를 분리했습니다.

1. `test/` 폴더의 해당 `.dat` 파일을 JAR 파일과 같은 폴더로 복사하고 파일명을 `scheduleData.dat`로 변경합니다.
2. `java -jar ssd_ip_cp4_2026f_233343_app.jar` 명령으로 실행합니다.
3. 해당 `TEST*.md`에 적힌 순서대로 직접 등록·수정·삭제·자동 배치하고 결과를 확인합니다.
4. 다음 TEST로 넘어갈 때는 **프로그램을 완전히 종료한 후** 다음 `.dat`로 교체합니다.

## 기능 테스트 순서
| 순서 | 화면/기능 | 입력 또는 조작 | 기대 결과 |
|---|---|---|---|
| 1 | 주간표 | 10/26~11/01 주를 열고 시작 요일을 **토요일**로 선택 | 자동배치 준비 |
| 2 | 자동 배치 | **자동 배치** 클릭 | 월~금 `[자동]` 없음, 고정/금지 시간 미침범 |
| 3 | 토요일 결과 | 아래 '정확한 예상 배치' 표와 비교 | **5개 배치 성공, 1개 실패** |
| 4 | 결과 팝업 | 배치 실패 목록 확인 | `F_FAIL_600` 600분 / 마감 10/31 표시 |
| 5 | 주간 캐시 | 다음 주 이동 후 다시 이 주로 돌아오기 | 방금 배치된 결과 유지 (데이터를 변경하지 않은 경우) |
| 6 | 시작 요일 변경 | **수요일** 선택 후 자동 배치 재실행 | 월·화 제외, 수~일에서 새로 배치. `F_FAIL_600`도 10/28 이전이 아닌 10/28~10/31에 600분 빈 시간이 있으면 배치 **가능** |
| 7 | 시작 요일 변경 | **월요일** 선택 후 재실행 | 월~일 모두 배치 후보, 해당 날짜 범위 밖에는 배치 안 됨 |
